# Summary

**Provenance verification** is the technical validation step where consumers and deployment pipelines check that a software binary originated from an authenticated source repository and was generated by a trusted build service[^slsa-spec-v1-2].

# Verification Workflow
1. **Signature Verification**: Verifying cryptographic signatures using Sigstore Cosign or DSSE envelopes against expected public keys or OIDC identity claims.
2. **Builder Identity Validation**: Confirming that the builder platform (e.g., GitHub Actions reusable workflow, Google Cloud Build) matches authorized runner configurations.
3. **Source Commit Pinning**: Correlating artifact digests back to exact immutable Git commit hashes.

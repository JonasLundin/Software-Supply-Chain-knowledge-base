# Summary

Published on May 7, 2025, by the Department for Science, Innovation and Technology (DSIT) and the National Cyber Security Centre (NCSC), the **Software Security Code of Practice** provides guidance for organizations developing or selling software in the United Kingdom[^uk-software-security-code-of-practice].

> [!NOTE]
> **Voluntary Guidance**: The UK Code of Practice is non-binding government guidance intended to encourage secure-by-design development and supply chain transparency.

# Core Principles
1. **Secure Design and Development**: Integrating threat modeling, automated security testing, and strict code review into software pipelines.
2. **Supply Chain Visibility**: Generating software bills of materials (SBOMs) to track third-party dependencies and known weaknesses.
3. **Vulnerability Disclosure**: Operating public vulnerability coordination policies in line with international standards.

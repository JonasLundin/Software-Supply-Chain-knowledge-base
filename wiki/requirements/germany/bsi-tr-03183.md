# Summary

**BSI TR-03183 (Cyber Resilience Requirements for Manufacturers and Products)** defines technical criteria for software bills of materials (SBOMs) aligned with European regulatory objectives[^regulation-eu-2024-2847].

# Technical Requirements
- Mandates machine-readable formats (CycloneDX or SPDX).
- Requires precise package identification using Package URLs (purl) and Common Platform Enumerations (CPE).
- Establishes integrity validation via cryptographic signatures and digest records.

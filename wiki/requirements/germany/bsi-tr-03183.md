# Summary

**BSI TR-03183** is Germany's national technical guideline defining cyber resilience standards for software products[^bsi-tr-03183].

**Binding / contractual / guidance**: Technical rule binding for federal procurement and high-assurance German public systems.

# Multipart Structure and Versions
BSI TR-03183 is organized into three distinct parts:
- **Part 1: General Requirements (Version 1.0.0)**: Foundational principles for software security, development security, and life-cycle management.
- **Part 2: Software Bill of Materials (SBOM) (Version 2.1.0)**: Explicit requirements for SBOM content, formatting (preferring SPDX and CycloneDX), dependency depth, and cryptographic verification.
- **Part 3: Vulnerability Reports and Notifications (Version 1.0.0)**: Standardized formats and protocols for exchanging security advisories and machine-readable VEX notifications.

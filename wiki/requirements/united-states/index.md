# United States

Executive Order 14028, NTIA minimum elements 2021, CISA minimum elements 2026, OMB memoranda, agency attestation forms.

## Concepts

- [NIST SP 800-218: Secure Software Development Framework (SSDF)](ssdf-nist-sp-800-218.md) — Authoritative set of fundamental, sound secure software development practices organized into four core categories.
- [CISA Secure Software Development Attestation Form](cisa-self-attestation.md) — Mandatory federal attestation form requiring executive certification of compliance with NIST SP 800-218.
- [NTIA Minimum Elements for a Software Bill of Materials (SBOM)](ntia-minimum-elements.md) — The foundational United States federal baseline defining data fields, operational considerations, and support practices for SBOMs.

# Summary

**ISO/IEC 5962:2021** is the formal international standard representing the adoption of the Linux Foundation's Software Package Data Exchange (SPDX) specification version 2.2.1 through the JTC 1 fast-track process[^iso-iec-5962].

> [!NOTE]
> **Version Alignment**: ISO/IEC 5962:2021 specifically standardizes **SPDX version 2.2.1**. Later versions such as SPDX 2.3 and SPDX 3.0 build upon this foundation but are distinct specification releases.

# Scope of Standardization
- Canonical exchange format for software composition, licensing declarations, and integrity verification.
- Universal terminology for software packages, files, relationships, and license expressions.

ISO/IEC 5962:2021 is published by ISO/IEC under ISO copyright rules.

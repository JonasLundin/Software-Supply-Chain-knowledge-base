# Summary

**SLSA (Supply-chain Levels for Software Artifacts)** is a security framework organized as graduated levels providing verifiable guarantees of artifact integrity and build isolation[^regulation-eu-2024-2847].

# The SLSA Levels
- **SLSA Build L1**: Provenance exists showing how the artifact was produced.
- **SLSA Build L2**: Provenance is authenticated, generated by a hosted build platform.
- **SLSA Build L3**: Hardened build platform with isolated, hermetic, and reproducible environments.

# Vulnerability Exploitability eXchange (VEX)

Machine-readable assertions of whether a specific vulnerability impacts a software artifact.

## Concepts

- [CSAF VEX](csaf-vex.md): Common Security Advisory Framework (OASIS Profile 5).
- [OpenVEX](openvex.md): Lightweight, embeddable VEX specification.
- [CycloneDX VEX](cyclonedx-vex.md): Integrated vulnerability disclosure in CycloneDX BOMs.

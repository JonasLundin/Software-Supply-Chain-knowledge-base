# Attestation and provenance

in-toto, SLSA 1.2, DSSE, Sigstore (Fulcio, Rekor, cosign), SCITT, build provenance predicates.

## Concepts

- [SLSA v1.0 (Supply-chain Levels for Software Artifacts)](slsa-1-0.md) — Security framework establishing tamper-evident build levels, unforgeable provenance models, and integrity controls from source to package release.
- [SLSA v1.2 & Source Track Extensions](slsa-1-2.md) — Advanced supply-chain integrity specification defining the SLSA Source Track, two-person code reviews, hermetic build environments, and reproducible verification.
- [in-toto Attestation Framework](in-toto.md) — CNCF Graduated cryptographic framework for defining, recording, and verifying multi-step software supply chain pipelines and metadata envelopes.
- [Sigstore Signing and Verification Ecosystem](sigstore.md) — Open-source public infrastructure project for keyless cryptographic signing, certificate issuance (Fulcio), and transparent ledger verification (Rekor).
